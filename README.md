# llm_psychometrics

This repository contains code supporting the analyses reported in the study “Large language models as psychometric laboratories? Maybe not yet. Cautionary evidence from synthetic personality data”.

The repository includes:
- a Python script for generating synthetic questionnaire responses using a large language model via the OpenAI API;
- an R script for computing correlation matrices and matrix similarity indices.

Human data are not shared due to privacy constraints. Synthetic data can be regenerated by running the provided scripts.

## Requirements
- Python 3.x with required packages listed in the script header
- R (≥ 4.0)

An OpenAI API key is required to run the Python script and must be provided via an environment variable.
